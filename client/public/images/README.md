# Image replacement guide

The demo uses temporary event photography. Put the supplied images in this
folder and update the `img` object at the top of `src/main.jsx`.

- Hero: 1600 x 720, subject positioned on the right
- Event cards: 700 x 480
- Venue cards: 700 x 420
- Why Eventoria: 1000 x 700
- Wedding banner: 1000 x 650

Use paths such as `/images/hero.jpg` so Vite serves the files directly.
